## Cara Install / Clone Project

### 1. Persiapan

Pastikan sudah terpasang:

- [Git](https://git-scm.com/downloads)
- Code editor, misalnya [Visual Studio Code](https://code.visualstudio.com/)
- Browser modern (Chrome, Firefox, Edge)

### 2. Clone repository

Buka terminal (Git Bash / CMD / PowerShell), lalu jalankan:

```bash
git clone https://github.com/juliarta99/optimus-2026.git
cd optimus-2026
```

Tidak memakai Git? Klik tombol **Code → Download ZIP** di halaman GitHub, lalu ekstrak file-nya.

## Belajar Selanjutnya Setelah HTML & CSS Dasar

### 1. CSS Lanjutan & Responsive Design

- **Flexbox** dan **CSS Grid** secara mendalam
- **Media query** dan pendekatan *mobile-first*
- Unit relatif: `rem`, `em`, `%`, `vw`, `vh`, dan fungsi `clamp()`
- **CSS Variables** (`:root { --color-primary: ... }`)
- Transisi & animasi (`transition`, `@keyframes`)
- Penamaan class yang rapi, misalnya metodologi **BEM**

📖 Referensi: [MDN Web Docs – CSS](https://developer.mozilla.org/id/docs/Web/CSS), [CSS-Tricks Flexbox Guide](https://css-tricks.com/snippets/css/a-guide-to-flexbox/), [Flexbox Froggy](https://flexboxfroggy.com/), [Grid Garden](https://cssgridgarden.com/)

### 2. JavaScript Dasar

- Variabel, tipe data, kondisi, perulangan, dan function
- **DOM Manipulation** (`querySelector`, `addEventListener`, `classList`) — seperti di `script.js` project ini
- Array & object, `fetch()` untuk mengambil data dari API
- ES6+: arrow function, destructuring, template literal, `async/await`

📖 Referensi: [javascript.info](https://javascript.info/), [MDN – JavaScript](https://developer.mozilla.org/id/docs/Web/JavaScript)

### 3. Framework CSS

Membantu membuat tampilan lebih cepat dan konsisten.

- **Tailwind CSS** — *utility-first*, styling langsung lewat class di HTML (`class="flex gap-4 p-6"`)
- **Bootstrap** — komponen siap pakai (navbar, card, modal)

📖 Referensi: [tailwindcss.com](https://tailwindcss.com/docs), [getbootstrap.com](https://getbootstrap.com/)

### 4. Git & GitHub

- Perintah dasar: `git init`, `add`, `commit`, `push`, `pull`
- Branch dan *pull request*
- Deploy website gratis dengan **GitHub Pages**, **Netlify**, atau **Vercel**

📖 Referensi: [Git Handbook](https://docs.github.com/en/get-started/using-git/about-git), [Learn Git Branching](https://learngitbranching.js.org/)

### 5. Framework JavaScript (Frontend)

Setelah nyaman dengan JavaScript:

- **React** (atau Next.js), **Vue**, atau **Svelte**
- Konsep komponen, *state*, dan *props*
- Package manager: **npm** / **pnpm**, dan build tool seperti **Vite**

📖 Referensi: [react.dev](https://react.dev/), [vuejs.org](https://vuejs.org/)

### 6. Backend & Database

Agar website bisa menyimpan dan mengolah data (misalnya form kontak, login, blog).

- **Backend:** Node.js + Express, PHP + Laravel, atau Python + Django/Flask
- **Database SQL:** MySQL, PostgreSQL — belajar query `SELECT`, `INSERT`, `UPDATE`, `DELETE`, dan relasi tabel
- **Database NoSQL:** MongoDB
- **REST API:** cara frontend dan backend saling berkomunikasi
- Alternatif cepat (*Backend as a Service*): **Firebase** atau **Supabase**

📖 Referensi: [SQLBolt](https://sqlbolt.com/), [Laravel Docs](https://laravel.com/docs), [Express.js](https://expressjs.com/)

### 7. Topik Pendukung Lainnya

- **Aksesibilitas (a11y):** HTML semantik, atribut `alt` & `aria-*`, kontras warna
- **SEO dasar:** meta tag, struktur heading, performa halaman
- **Optimasi performa:** kompres gambar (format WebP), *lazy loading*
- **UI/UX Design:** belajar desain di **Figma** sebelum coding
- **TypeScript:** JavaScript dengan tipe data, banyak dipakai di project besar
